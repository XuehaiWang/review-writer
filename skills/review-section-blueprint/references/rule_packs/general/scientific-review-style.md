# General scientific review style

- Write formal synthesis rather than a list of paper summaries.
- Open with the section's organizing claim, then compare sources on shared evidence axes.
- Prefer precise verbs such as `reported`, `measured`, `observed`, `supported`, and `proposed`.
- Use conditional language for interpretations not directly established by the evidence.
- Preserve method, dataset or sample, conditions, outcome metrics, and limitations when review-relevant.
- Do not call a method broad, robust, superior, efficient, or general without comparative evidence.
- Compress repetitive examples into class-level trends while retaining meaningful boundaries and counterexamples.
- Keep terminology consistent with the current project taxonomy and selected outline.
- Never import entities, headings, or conclusions from a reference review when they are absent from the current evidence.
