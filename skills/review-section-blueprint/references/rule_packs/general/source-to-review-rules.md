# Source-to-review rules

- Use only claims supported by the assigned source evidence.
- Preserve the distinction between measured results, author interpretation, and reviewer synthesis.
- Keep numerical results attached to the paper and experimental context that reported them.
- Compare papers on explicit common axes; do not merge incompatible populations, methods, or endpoints.
- State missing evidence and limitations instead of filling gaps with plausible details.
- Use the project's topic vocabulary and never copy subject-specific headings from an unrelated reference outline.
